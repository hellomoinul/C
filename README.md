# C Practice — Beginner Programs

Beginner C programs written for coursework practice: arrays, functions, strings, number patterns, series and small problem-solving exercises.

## What's inside

| Files | Topic |
|-------|-------|
| `array*.c` | Arrays |
| `function*.c`, `Function*.c`, `fubction9.c` | Functions |
| `string*.c`, `frequencystring.c` | Strings |
| `pattern*.c` | Star/number patterns |
| `series*.c` | Number series |
| `problem*.c` | Practice problems |

## Run

```bash
gcc <file>.c -o <file> && ./<file>
```

> Compiled with GCC. `.exe` files in the repo are Windows build outputs.
